# جيعان فبومرداس؟ الحل لعندك!

موقع طلبات أكل للطلبة، توصيل في كامل بومرداس مع Fast Delivery.

## النشر على GitHub Pages
1. أنشئ حساباً على github.com ثم اضغط New repository.
2. سمِّ المستودع مثلاً `boumerdes-food` واجعله Public.
3. اضغط Add file ثم Upload files، وارفع `index.html` و`README.md`، ثم Commit changes.
4. ادخل Settings ثم Pages. في Source اختر Deploy from a branch.
5. اختر الفرع `main` والمجلد `/ (root)` ثم Save.
6. بعد دقيقة أو دقيقتين يظهر الموقع على: `https://USERNAME.github.io/boumerdes-food/`

للحصول على رابط أقصر `https://USERNAME.github.io/` سمِّ المستودع `USERNAME.github.io`.

## التعديل
- **رقم واتساب:** في `index.html` ابحث عن `WA_NUMBER` وضع الرقم بالصيغة الدولية بدون +، مثال `213555123456`.
- **الأسعار والأطباق:** عدّل القائمة `items` في نفس الملف.
